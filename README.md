# Blog Autowriter

Claude API로 이번 주 개발/기술 토픽을 찾아주고, 원하는 스타일로 블로그 글을 생성해주는 도구.
발행은 대상에 따라 다릅니다:
- **모의 블로그**: Playwright로 완전 자동 포스팅되는 데모.
- **Velog / Tistory**: Cloudflare가 자동화 브라우저의 쓰기 동작을 막기 때문에 완전 자동 발행은
  불가능합니다. 대신 컴패니언 크롬 확장(`extension/`)이 콘텐츠를 실제 로그인된 브라우저 안에서
  제목/태그/본문까지 채워주고, 최종 "출간하기"만 사용자가 직접 누르는 반자동 방식입니다.

대시보드(토픽 검색/글 생성/설정)는 별도 웹서버가 아니라 **크롬 확장 안에 내장**되어 있습니다 —
이유는 `extension/README.md` 참고 (로컬 포트 충돌 문제 회피).

## 실행 준비

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # 없어도 기동은 되지만, Settings 화면에서 키를 등록해야
                                       # 글 생성이 됩니다 (아래 참고)
```

```bash
cd backend && mvn spring-boot:run     # http://localhost:8091
cd frontend && npm install && npm run build   # ../extension/webapp/ 에 대시보드 빌드
```

그다음 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드합니다" → `extension/`
폴더 선택. 자세한 설치/사용법은 `extension/README.md`.

## 사용 흐름

1. 확장 아이콘 클릭 → 대시보드가 새 탭으로 열립니다.
2. **이번 주 토픽 불러오기** — Claude의 `web_search` 도구로 최근 7일 이내 한국/해외 주요
   기술 뉴스·트렌드·릴리즈 소식을 조사해 블로그 글감으로 좋은 주제 10개를 요약과 출처
   링크와 함께 보여줍니다. 검색이 여러 번 이뤄지기 때문에 응답까지 수 분 걸릴 수 있습니다.
3. 토픽 카드를 클릭하면 "주제" 입력란에 채워지고, 원하는 스타일 프리셋과 AI 모델을 골라
   **생성하기**를 누르면 제목/태그/본문이 만들어집니다.
4. 포스팅 대상을 고릅니다.
   - **모의 블로그 (자동 데모)**: 버튼 한 번으로 Playwright가 로컬 목업 블로그에 자동
     로그인·작성·발행까지 끝내고 스크린샷을 남깁니다.
   - **Velog / Tistory (확장 프로그램)**: "확장 프로그램 대기열에 추가"를 누르면 콘텐츠가
     생성·저장됩니다. 실제 Velog/Tistory 글쓰기 페이지를 열면 배너가 뜨고, "채우기"를 누르면
     제목/태그/본문이 자동으로 채워집니다 — 발행 버튼만 직접 누르면 됩니다. 발행 이력에서
     진행 상황(대기 중 → 채워짐 → 발행 완료)이 실시간으로 갱신됩니다.

## 설정 화면

확장 배너의 ⚙ 버튼이나 대시보드의 "설정" 버튼으로 들어갑니다.

- **Claude API 키**: 환경 변수(`ANTHROPIC_API_KEY`)가 없어도 여기서 저장하면 됩니다 — 로컬
  파일(`backend/data/anthropic-api-key.txt`, git에 안 올라감)에 저장되고, 셸을 새로 열어도
  유지됩니다. 환경 변수가 설정돼 있으면 그쪽이 항상 우선합니다.
- **Tistory 새 글 작성 URL**: 사용자마다 블로그 주소가 달라서, 자기 블로그의 "새 글 작성" 페이지
  URL을 한 번만 붙여넣어두면 이후 재사용됩니다.
- **기본 작성 스타일**: 글감 생성 화면을 열 때 기본으로 선택될 스타일 프리셋/AI 모델.

## 왜 Velog/Tistory는 완전 자동 발행이 안 되나요 (2026-08-10)

처음에는 Playwright로 Velog 로그인 세션을 재사용해 제목/태그/본문 입력부터 "임시저장",
최종적으로 "출간하기"까지 자동화하려 했습니다. 그런데 실제 계정으로 테스트한 결과,
**Cloudflare가 Playwright로 띄운 브라우저에서 발생하는 쓰기 동작(임시저장 포함)을 거의 전부
차단**한다는 것을 확인했습니다. 번들 Chromium은 물론 `channel: "chrome"`으로 진짜 설치된
크롬 바이너리를 띄워도 동일하게 막혔고, 반면 사람이 직접 조작하는 것과 동일하게 인식되는
브라우저 확장(예: 이미 로그인된 실제 크롬 세션에 붙는 방식)으로 같은 버튼을 누르면 정상
동작했습니다. 즉 브라우저 종류가 아니라 Playwright/CDP가 브라우저에 남기는 자동화 신호
(`navigator.webdriver` 등)가 원인으로 보입니다.

이걸 우회하려면 지문(fingerprint) 위장이나 스텔스 패치 같은 봇 탐지 회피 기법이 필요한데,
그런 코드는 작성하지 않기로 했습니다. 대신 **진짜 크롬 확장**(`extension/`)이 사용자의 실제
로그인된 브라우저 안에서 제목/태그/본문만 채우고, 최종 발행 버튼은 항상 사용자가 직접 누르는
반자동 방식으로 전환했습니다 — 자세한 배경은 `extension/README.md` 참고.

`target: MOCK`은 이 문제와 무관하게 로그인부터 발행까지 전체 파이프라인을 완전 자동으로
시연할 수 있습니다.

## 스타일 프리셋

콘텐츠는 실제 블로그 글을 스크래핑하지 않고, 회고형/트러블슈팅형/튜토리얼형/기술설명형
4가지 구조·톤 가이드(`StylePresetService`)를 프롬프트에 반영해 생성합니다.

## AI 모델 선택

생성 화면과 예약 등록 화면에서 `claude-haiku-4-5`(빠르고 저렴)와 `claude-sonnet-5`(고품질)
중 하나를 골라 사용할 수 있습니다. `ClaudeService`는 `output_config.format`(구조화된 출력)으로
호출해서 title/tags/content가 항상 유효한 JSON으로 오도록 보장합니다. 주간 토픽 조사는
`web_search` 도구를 함께 써야 해서 항상 `claude-sonnet-5`로 고정되어 있습니다.

## 예약

주제/스타일/모델/대상을 정해 1회 또는 반복(cron) 예약을 걸어둘 수 있습니다. 예약이 발화되면
콘텐츠가 생성되고, 대상이 MOCK이면 바로 발행까지, Velog/Tistory면 확장 프로그램 대기열에
등록됩니다 (실제 채우기는 나중에 해당 글쓰기 페이지를 열었을 때 이뤄집니다).
