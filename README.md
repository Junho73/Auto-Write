# Playwright Blog Autowriter

Claude API로 이번 주 개발/기술 토픽을 찾아주고, 원하는 스타일로 블로그 글을 생성해주는 도구.
발행은 대상에 따라 다릅니다: **모의 블로그**는 Playwright로 완전 자동 포스팅되는 데모이고,
**Velog**는 보안(Cloudflare 봇 차단) 문제로 자동 발행이 불가능해 콘텐츠만 생성해주고
사용자가 직접 복사해서 붙여넣습니다.

## 실행 준비

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # 필수. 없으면 백엔드 기동 실패.
```

```bash
cd backend && mvn spring-boot:run   # http://localhost:8091
cd frontend && npm install && npm run dev   # http://localhost:5173 (또는 지정한 포트)
```

## 사용 흐름

1. **이번 주 토픽 불러오기** — Claude의 `web_search` 도구로 최근 7일 이내 한국/해외 주요
   기술 뉴스·트렌드·릴리즈 소식을 조사해 블로그 글감으로 좋은 주제 10개를 요약과 출처
   링크와 함께 보여줍니다. 검색이 여러 번 이뤄지기 때문에 응답까지 수 분 걸릴 수 있습니다.
2. 토픽 카드를 클릭하면 "주제" 입력란에 채워지고, 원하는 스타일 프리셋과 AI 모델을 골라
   **생성하기**를 누르면 제목/태그/본문이 만들어집니다.
3. 포스팅 대상을 고릅니다.
   - **모의 블로그 (자동 데모)**: 버튼 한 번으로 Playwright가 로컬 목업 블로그에 자동
     로그인·작성·발행까지 끝내고 스크린샷을 남깁니다.
   - **Velog (직접 붙여넣기)**: "복사하기"로 제목+본문을 클립보드에 복사한 뒤, "Velog 새 글
     작성 열기"로 `velog.io/write`를 새 탭으로 열어 붙여넣고 태그를 입력해서 직접
     발행하면 됩니다. 발행 이력에도 같은 복사 버튼과 링크가 남아 나중에 다시 쓸 수 있습니다.

## 왜 Velog는 자동 발행이 안 되나요 (2026-08-10)

처음에는 Playwright로 Velog 로그인 세션을 재사용해 제목/태그/본문 입력부터 "임시저장",
최종적으로 "출간하기"까지 자동화하려 했습니다. 그런데 실제 계정으로 테스트한 결과,
**Cloudflare가 Playwright로 띄운 브라우저에서 발생하는 쓰기 동작(임시저장 포함)을 거의 전부
차단**한다는 것을 확인했습니다. 번들 Chromium은 물론 `channel: "chrome"`으로 진짜 설치된
크롬 바이너리를 띄워도 동일하게 막혔고, 반면 사람이 직접 조작하는 것과 동일하게 인식되는
브라우저 확장(예: 이미 로그인된 실제 크롬 세션에 붙는 방식)으로 같은 버튼을 누르면 정상
동작했습니다. 즉 브라우저 종류가 아니라 Playwright/CDP가 브라우저에 남기는 자동화 신호
(`navigator.webdriver` 등)가 원인으로 보입니다.

이걸 우회하려면 지문(fingerprint) 위장이나 스텔스 패치 같은 봇 탐지 회피 기법이 필요한데,
그런 코드는 작성하지 않기로 했습니다. 그래서 Velog 관련 Playwright 자동화 코드는 전부
제거했고, 대신 콘텐츠 생성까지만 자동화하고 실제 발행은 사용자가 직접 복사·붙여넣기로
마무리하는 방식으로 전환했습니다.

`target: MOCK`은 이 문제와 무관하게 로그인부터 발행까지 전체 파이프라인을 완전 자동으로
시연할 수 있습니다.

## 스타일 프리셋

콘텐츠는 실제 블로그 글을 스크래핑하지 않고, 회고형/트러블슈팅형/튜토리얼형/기술설명형
4가지 구조·톤 가이드(`StylePresetService`)를 프롬프트에 반영해 생성합니다.

## AI 모델 선택

생성 화면과 예약 등록 화면에서 `claude-haiku-4-5`(빠르고 저렴)와 `claude-sonnet-5`(고품질)
중 하나를 골라 사용할 수 있습니다. `ClaudeService`는 `output_config.format`(구조화된 출력)으로
호출해서 title/tags/content가 항상 유효한 JSON으로 오도록 보장합니다. 주간 토픽 조사는
`web_search` 도구를 함께 써야 해서 항상 `claude-sonnet-5`로 고정되어 있습니다.

## 예약

주제/스타일/모델/대상을 정해 1회 또는 반복(cron) 예약을 걸어둘 수 있습니다. 예약이 발화되면
콘텐츠가 생성되고, 대상이 MOCK이면 바로 발행까지, VELOG면 이력에 생성 결과만 저장됩니다
(발행 이력 화면에서 나중에 복사해서 쓰면 됩니다).
