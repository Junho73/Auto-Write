# Blog Autowriter Assistant (Chrome 확장)

Blog Autowriter 웹앱에서 Velog/Tistory로 "확장 프로그램 대기열에 추가"한 글을, 실제로 로그인된
크롬에서 글쓰기 페이지를 열었을 때 제목/태그/본문까지 자동으로 채워주는 도우미입니다.
**최종 발행 버튼은 항상 직접 눌러야 합니다** — 이 확장은 그 버튼을 대신 누르지 않습니다.

## 설치 (개발자 모드)

1. 백엔드가 `http://localhost:8091`에서 떠 있어야 합니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 "개발자 모드" 켜기
4. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 `extension/` 폴더 선택

## 동작 방식

- `velog.io/write*` 또는 `*.tistory.com/manage/*` 페이지를 열면, 대기 중인 글이 있는지 백엔드에
  물어봅니다.
- 있으면 화면 우측 하단에 "이 글을 채울까요?" 배너가 뜹니다 — 아무 글쓰기 페이지나 열었을 때 갑자기
  내용이 덮어써지지 않도록, 항상 확인을 먼저 거칩니다.
- "채우기"를 누르면 제목/태그/본문을 채우고, 배너가 "출간하기는 직접 눌러주세요"로 바뀝니다.
- Velog는 발행 후 URL이 `/write`를 벗어나는 걸 감지해서 자동으로 "발행 완료"로 기록을 시도합니다
  (best-effort). 안 되면 웹앱의 발행 이력에서 "발행 완료로 표시"를 직접 눌러주면 됩니다.

## 현재 상태 / 알려진 제한

- **Velog 셀렉터는 실계정으로 검증됨** (`content-velog.js`).
- **Tistory 셀렉터는 아직 미검증**입니다 (`content-tistory.js`) — 실제 마크다운 에디터 화면을 보면서
  선택자를 맞춰야 합니다. 안 맞으면 배너에 에러가 표시되고 웹앱 발행 이력에도 실패로 기록됩니다.
- 여러 개의 글이 큐에 쌓여 있으면 가장 오래된 것부터(FIFO) 채웁니다. 특정 글을 골라서 채우는 기능은
  아직 없습니다.
