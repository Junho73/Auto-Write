# Blog Autowriter Assistant (Chrome 확장)

Blog Autowriter 대시보드(토픽 검색/글 생성/설정)를 확장 안에 내장하고, Velog/Tistory로
"확장 프로그램 대기열에 추가"한 글을, 실제로 로그인된 크롬에서 글쓰기 페이지를 열었을 때
제목/태그/본문까지 자동으로 채워주는 도우미입니다.
**최종 발행 버튼은 항상 직접 눌러야 합니다** — 이 확장은 그 버튼을 대신 누르지 않습니다.

## 설치 (개발자 모드)

1. 백엔드를 띄웁니다 — `cd backend && mvn spring-boot:run` (`http://localhost:8091`)
2. 대시보드를 빌드해서 확장 안에 넣습니다 — `cd frontend && npm run build`
   (`../extension/webapp/`에 결과물이 생깁니다. 대시보드 코드를 고칠 때마다 다시 실행해야 합니다.)
3. 크롬 주소창에 `chrome://extensions` 입력
4. 우측 상단 "개발자 모드" 켜기
5. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 `extension/` 폴더 선택

## 대시보드는 어떻게 여나요

- 툴바의 확장 아이콘 클릭 → 대시보드(토픽 검색/생성 화면)가 새 탭으로 열립니다.
- Velog/Tistory 글쓰기 페이지에 뜨는 배너 우측 상단 **⚙** 버튼 → 설정 화면(API 키/Tistory
  URL/기본 스타일)이 새 탭으로 열립니다.
- 둘 다 `chrome-extension://<확장ID>/webapp/...`로 열립니다 — 로컬 포트를 전혀 안 쓰기 때문에,
  WSL이나 다른 로컬 서버가 특정 포트를 차지하고 있어도 영향을 안 받습니다 (아래 참고).

## 동작 방식 (글 채우기)

- `velog.io/write*` 또는 `*.tistory.com/manage/*` 페이지를 열면, 대기 중인 글이 있는지 백엔드에
  물어봅니다.
- 있으면 화면 우측 하단에 "이 글을 채울까요?" 배너가 뜹니다 — 아무 글쓰기 페이지나 열었을 때 갑자기
  내용이 덮어써지지 않도록, 항상 확인을 먼저 거칩니다.
- "채우기"를 누르면 제목/태그/본문을 채우고, 배너가 "출간하기는 직접 눌러주세요"로 바뀝니다.
- Velog는 발행 후 URL이 `/write`를 벗어나는 걸 감지해서 자동으로 "발행 완료"로 기록을 시도합니다
  (best-effort). 안 되면 웹앱의 발행 이력에서 "발행 완료로 표시"를 직접 눌러주면 됩니다.

## 왜 대시보드를 별도 서버 대신 확장 안에 넣었나 (2026-08-17)

원래는 대시보드를 `npm run dev`로 띄운 Vite 개발 서버(localhost:3000)에서 열었는데, 개발 머신에
WSL2로 상시 구동 중인 팀 서버(PlayOps)가 있고 그 안 Docker 컨테이너가 3000/8080 포트를 물고
있었습니다. WSL이 `nat` 네트워킹 모드라 Windows의 `127.0.0.1:포트` 요청이 WSL 안에 뭔가 그 포트를
듣고 있으면 자동으로 그쪽으로 릴레이돼서(`wslrelay.exe`), 확장이 대시보드를 열려고 할 때마다
PlayOps가 대신 튀어나오는 문제가 있었습니다. 대시보드를 빌드해서 확장 안에 정적 파일로 넣으면
`chrome-extension://` 주소로 열려서 이 문제 자체가 발생할 수 없습니다. 백엔드(Spring Boot)는
예약 발행(cron)·DB·실제 Claude API 호출 때문에 상시 서버 프로세스가 필요해 확장 안으로 옮길 수
없고, `8091` 고정 포트로 계속 남아있습니다 (WSL 쪽 리스닝 포트와 겹치지 않는 것 확인됨).

## 현재 상태 / 알려진 제한

- **Velog 셀렉터는 실계정으로 검증됨** (`content-velog.js`).
- **Tistory 셀렉터는 아직 미검증**입니다 (`content-tistory.js`) — 실제 마크다운 에디터 화면을 보면서
  선택자를 맞춰야 합니다. 안 맞으면 배너에 에러가 표시되고 웹앱 발행 이력에도 실패로 기록됩니다.
- 여러 개의 글이 큐에 쌓여 있으면 가장 오래된 것부터(FIFO) 채웁니다. 특정 글을 골라서 채우는 기능은
  아직 없습니다.
